# Watch Worksheet作成君

時計の米国税関ワークシート（FedEx新形式）を商品情報から作成し、PDF保存・印刷できるChrome拡張機能です。

## 概要

時計の国際発送に必要なFedEx形式の米国税関ワークシートを、商品情報を入力するだけで自動生成します。作成したワークシートはPDF保存または印刷して使用できます。

## 主な機能

- **2種類の入力方式**: 商品情報を直接入力する方式と、ChatGPTの出力を貼り付ける方式に対応
- **原産国自動セット**: 商品情報から原産国を自動で設定
- **素材選択**: 時計の素材（ケース・ベルト等）を選択して入力
- **HTSUS候補表示**: 時計の関税分類番号（HTSUS）の候補を提示
- **価格按分**: 複数部品の価格を自動按分
- **確認ウィザード**: 入力内容を段階的に確認するウィザード形式
- **PDF出力**: 完成したワークシートをPDFで保存または印刷

## プライバシー

- 入力したデータはすべてブラウザ内（ローカルストレージ）にのみ保存されます。
- 外部サーバーや第三者への情報送信は一切行いません。

詳細は[プライバシーポリシー](https://naokijodan.github.io/watch-worksheet-extension/privacy.html)をご覧ください。
