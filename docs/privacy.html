収集する情報について

本拡張機能は個人情報を収集しません。設定画面で入力する会社名・氏名・メールアドレス、 OpenAI APIキー、およびワークシート作成のための商品情報は、すべて利用者のブラウザ内 （ローカルストレージ）にのみ保存されます。これらの情報を開発者が受け取ることはありません。

外部への情報送信について

本拡張機能には、AI商品ページ読み取り機能が含まれます。この機能を使用した場合、 現在開いている商品ページの商品名・説明文・ブランド等のテキスト情報が、 利用者ご自身が設定した OpenAI APIキーを用いて OpenAI のサーバーへ送信されます。

また、AIによる読み取り精度向上のため、商品ページに掲載されている商品画像（最大3枚、画像URLの参照）を送信する場合があります。

送信されるのは商品ページの公開情報（テキストおよび商品画像）のみです。会社情報・APIキー・個人情報は 送信されません。OpenAI への情報送信は利用者がボタンを押した場合にのみ行われます。 OpenAI のデータ取り扱いについては、 OpenAI プライバシーポリシー をご参照ください。

AI読み取り機能を使用しない場合、外部への情報送信は一切行われません。 すべてのデータ処理はお使いのブラウザ内で完結します。

第三者への情報提供

OpenAI を除き、第三者への情報提供は行いません。

データの削除について

拡張機能を削除するか、ブラウザのデータ消去（ローカルストレージのクリア）を行うことで、 保存されている設定情報（会社情報・APIキー等）はすべて削除されます。

使用する権限について

  • ストレージ (storage): 会社情報・APIキー等の設定を端末内に保存するために使用します。
  • サイドパネル (sidePanel): ツール画面を表示するために使用します。
  • アクティブタブ (activeTab) / スクリプト実行 (scripting) / タブ (tabs): AI読み取り機能使用時に、現在開いている商品ページのテキスト情報を取得するために使用します。 利用者がAI読み取りボタンを押した場合にのみ動作します。
